1. Lap Time Trend

Each completed lap's time as a solid line; the dashed line projects the remaining laps using the recent-2-lap average pace. The meta below shows projected finish vs the 38h cutoff using lap+pit cycle time.

2. Mile Pace

Same data as #1 expressed in min/mile — the unit runners actually think in.

3. Lap-to-Lap Delta

How much slower (red, above zero) or faster (green, below) each lap was vs the previous. Yellow = within ±1 min. Big positive numbers signal fade.

4. Pit Times

Time at each pit stop. Color-coded: green ≤ 15 min, yellow 15-25 min, red > 25 min.

5. Intake Rate (per hour, lap+pit cycle)

Per-hour calorie, fluid, and sodium intake by lap, treating each lap+pit as one cycle. Dashed line is the target; trends matter more than any single point.

6. Cumulative Progress vs Cutoffs

Miles done over race-clock elapsed. The diagonal is the constant pace that lands at the 38h cutoff; the yellow line is the 35h "lap 10 must start" gate; the red line is the 38h finish cutoff.
